# Complete Clarity Solicitors: client facts

Complete Clarity Solicitors (completeclaritysolicitors.com). Scottish firm; this work covers residential property and conveyancing pages. Offices in Glasgow, Edinburgh and East Kilbride, acting across Scotland. Drop-in HTML content work started 24 Sep 2026.

## Client-specific rules (override the general defaults in SKILL.md)
- **CSS delivery: stylesheet, shared across pages.** One stylesheet serves every property page. It lives in WordPress Appearance > Customise > Additional CSS; the source copy is `references/clients/complete-clarity-shared.css`. Builds ship the HTML fragment only, with no `<style>`. If a page needs a component the stylesheet lacks, supply only the extra rules as a separate snippet to append to the Customiser and to `complete-clarity-shared.css`.
- **One shared root id: `#ccs-property-block`**, used once per page on every property page. This is a deliberate exception to "a unique ID per client/page": the shared stylesheet is scoped to it.
- **Class prefix `ccsp-`.** Existing components: `ccsp-section`, `ccsp-lead`, `ccsp-jump`, `ccsp-cta-row`, `ccsp-btn ccsp-btn-primary`, `ccsp-btn ccsp-btn-secondary`, `ccsp-cards`/`ccsp-card`, `ul.ccsp-list`, `ccsp-profile`/`ccsp-role`, `ccsp-steps`/`ccsp-step`/`ccsp-num`/`ccsp-step-body`, `details.ccsp-faq`/`ccsp-faq-a`, `ccsp-cta-final`, `ccsp-disclaimer`. Reuse these for consistency across the client's own pages; the pattern log applies across clients, not within this client's property section.
- **Regression check:** run `python3 scripts/check-block.py <fragment>.html references/clients/complete-clarity-shared.css`. Expected warnings: the `!important` count (31) and "stylesheet header does not name the fragment" for any fragment not yet listed. Add each new fragment to the "Fragments that use it" list in the shared CSS header, in both the Customiser and this folder.
- **The block replaces the main body column only.** The Elementor hero (H1 and intro line) and the sidebar stay. Flag any hero mismatch with the approved copy in the handover.
